Rèn luyện kỹ năng tạo, đổi tên, sao chép, di chuyển, xóa, khôi phục tệp tin và thư mục trên Windows 11.

Hình 4: Bên trong thư mục Documents

Hình 8: Bên trong thư mục

Hình 9: Tạo file text
Hình 10: File GhiChu.txt đã tạo

Hình 12: File đã đổi tên

Hình 13: Chọn New → Folder
Hình 14: Đặt tên TaiLieu
Hình 15: Thư mục TaiLieu đã tạo
8 Sao chép tệp tin (Copy & Paste)

Copy GhiChuQuanTrong.txt (Ctrl + C) → vào TaiLieu → Paste (Ctrl + V).

Hình 16: Mở thư mục TaiLieu
Hình 17: Chọn Paste
Hình 18: File đã sao chép thành công
9 Di chuyển tệp tin (Cut & Paste)

Tạo file DiChuyen.txt → Cut (Ctrl + X) → vào TaiLieu → Paste (Ctrl + V).

Hình 19: Tạo file DiChuyen.txt
Hình 20: Chọn Cut
Hình 21: File đã di chuyển sang TaiLieu

Chuột phải vào GhiChuQuanTrong.txt → Delete → vào thùng rác.

Hình 23: Chọn Delete
Hình 24: File đã vào Recycle Bin
11 Xóa vĩnh viễn

Chọn DiChuyen.txt → nhấn Shift + Delete → xóa vĩnh viễn.

Hình 25: Cảnh báo xóa vĩnh viễn
Hình 26: File đã bị xóa vĩnh viễn
12 Khôi phục từ Thùng rác

Mở Recycle Bin → chuột phải vào file → Restore.

Hình 27: Chọn Restore để khôi phục
